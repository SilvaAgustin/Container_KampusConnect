Getting Started with Docker

Pelajari cara memverifikasi instalasi Docker dan menjalankan container pertama Anda melalui terminal.

powershell — docker run hello-world
docker run hello-world

Perintah ini akan mengunduh image uji dan mencetak pesan sukses.

powershell — nginx server
docker run -d --name my-web -p 8080:80 nginx:alpine

Buka browser ke http://localhost:8080 untuk melihat web server berjalan.

Building Custom Images

Pelajari cara mengemas aplikasi Anda sendiri ke dalam Docker Image menggunakan Dockerfile.

Dockerfile 
FROM node:18-alpine
WORKDIR /app
COPY . .
RUN npm install
EXPOSE 3000
CMD ["node", "index.js"]
powershell
docker build -t my-app:1.0 .

Troubleshooting Guide

Solusi cepat untuk masalah umum yang sering dihadapi developer saat menggunakan Docker.

Penyebab: Docker Engine (Docker Desktop) sedang tidak berjalan di latar belakang.

Solusi: Buka aplikasi Docker Desktop, tunggu hingga status "Engine Running" (ikon berwarna hijau), lalu jalankan kembali perintah Anda di terminal.

Penyebab: Port yang ingin Anda gunakan (misal 8080) sudah dipakai oleh aplikasi atau container lain.

Solusi: Hentikan container yang sedang berjalan dengan docker ps lalu docker stop [CONTAINER_ID], atau ubah port di perintah run Anda menjadi -p 8081:80.
